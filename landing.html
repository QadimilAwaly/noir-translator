Dibangun Khusus untuk Penerjemahan Literatur Novel Skala Panjang

Penerjemahan novel ratusan bab menuntut konsistensi istilah yang tidak terputus, konsumsi daya yang bersahabat di perangkat bergerak, serta integritas data fisik yang terisolasi aman.

01 / RETENSI KONTEKS & GLOSARIUM DINAMIS

Ekstraksi Istilah Cerdas & Proteksi Karakter

Noir Translator memindai bab sebelum diterjemahkan untuk menyaring entitas glosarium yang relevan saja. Didukung penandaan gender tokoh eksplisit untuk mengeliminasi kesalahan fatal kata ganti orang ketiga (ia/dia/beliau) yang kerap melanda mesin penerjemah umum.

  • Unicode-aware keyword matching (CJK, Latin, Hangul, Vietnamese)
  • Pencegahan injeksi prompt tak tepercaya melalui delimiter terenkapsulasi
  • Glosarium global & per-novel otomatis disinkronkan
02 / STORAGE ENGINE

Granular Markdown Storage & Zero Flash Wear

Menghentikan pola usang penulisan seluruh bab berulang kali ke penyimpanan fisik. Mesin kami mendeteksi perubahan isi (*dirty-checking*) dan hanya menulis file Markdown bab yang benar-benar dimodifikasi.

  • Penyimpanan per bab dalam format Markdown murni yang manusiawi
  • Hemat hingga 98% siklus I/O disk pada novel ratusan bab
  • Dukungan struktur folder fisik lokal yang mudah di-backup
03 / DAYA & JARINGAN

HTTP Keep-Alive & Optimasi Radio Modem

Di perangkat seluler atau tablet Wi-Fi, handshake TLS/TCP baru pada setiap bab dapat menguras baterai ponsel dengan membangunkan radio modem berulang kali. Noir Translator mempertahankan pool koneksi persisten untuk latensi instan dan hemat daya.

  • Socket pooling HTTP/HTTPS keep-alive dengan 30s timeout
  • Lazy on-demand rate-limit pruning tanpa interval latar belakang
  • Throttling refetch jendela aktif untuk mencegah request liar
04 / KEAMANAN & PROVIDER

Dual Engine & Keamanan Sandboxing Ketat

Pilih provider terbaik sesuai gaya tulisan: kecepatan Gemini Flash atau kekayaan rasa Claude 3.5 Sonnet & DeepSeek V3 lewat OpenRouter. Seluruh operasi file dipagari dengan proteksi path traversal (*sandboxed library base*).

  • Dukungan penuh Google Gemini Native (@google/genai) & OpenRouter
  • Sandboxing folder fisik mencegah eksploitasi traversal path
  • Autentikasi token timing-safe opsional saat dipapar ke jaringan

Jalankan Noir Translator dalam Hitungan Menit

Pilih lingkungan yang Anda gunakan. Kami menyediakan konfigurasi teruji untuk Android Termux, Linux, macOS, dan Windows. 

# 1. Update paket Termux & instal dependensi penting
pkg update && pkg upgrade -y
pkg install nodejs-lts git esbuild -y
termux-wake-lock

# 2. Atur binary esbuild Termux & clone repositori
export ESBUILD_BINARY_PATH=$(which esbuild)
git clone https://github.com/QadimilAwaly/noir-translator.git
cd noir-translator

# 3. Instal dependensi & atur API Key
npm install
cp .env.example .env.local

# 4. Build & jalankan dalam Mode Production (Sangat Hemat RAM ~35MB)
npm run build
npm start

# Buka browser ponsel: http://localhost:3131
